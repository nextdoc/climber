# References

Public work on agent loops that improve code or prompts against a metric, which this project draws on.

## Agent research loops

- Karpathy's autoresearch: a minimal propose, run, keep loop on a fixed metric and budget. Write-ups: [kingy.ai](https://kingy.ai/news/autoresearch-karpathys-minimal-agent-loop-for-autonomous-llm-experimentation/), [DataCamp](https://www.datacamp.com/tutorial/guide-to-autoresearch)
- [AlphaEvolve](https://arxiv.org/abs/2506.13131) (DeepMind, 2025): evolutionary coding agent with a program database
- [ShinkaEvolve](https://arxiv.org/abs/2509.19349) (Sakana, 2025): sample-efficient program evolution
- [AIDE](https://arxiv.org/abs/2502.13138): tree search over code for ML engineering
- [The AI Scientist v2](https://arxiv.org/abs/2504.08066): agentic tree search for automated research
- [AI research agents for machine learning](https://arxiv.org/abs/2507.02554): search policies studied on MLE-bench
- [MLE-bench](https://arxiv.org/abs/2410.07095): benchmark of ML engineering tasks for agents

## Prompt and program optimisation

- [TextGrad: Automatic "Differentiation" via Text](https://arxiv.org/abs/2406.07496) (2024)
- [EvoPrompt: Connecting Large Language Models with Evolutionary Algorithms Yields Powerful Prompt Optimizers](https://arxiv.org/abs/2309.08532) (2023)
- [MIPROv2: Optimizing Instructions and Demonstrations for Multi-Stage Language Model Programs](https://arxiv.org/abs/2406.11695) (2024)
- [DSPy](https://dspy.ai): framework documentation, including the [GEPA guide](https://dspy.ai/getting-started/gepa-optimization/) and the [optimizer overview](https://dspy.ai/learn/optimization/optimizers/)
